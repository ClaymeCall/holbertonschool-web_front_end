# Holberton School - Web Front-End

This repository and project were made in the context of learning at Holberton School. The project goal was to learn about web front-end development, including HTML5, CSS3, responsive design, and modern styling techniques.

## Repository Structure

- **CSS_advanced**: Advanced CSS techniques including selectors, box model, flexbox, grid, animations, and responsive design
- **html_advanced**: Advanced HTML5 features, semantics, accessibility, and forms
